# jspsych-adaptive-corsi-task
An adaptive visual CORSI task using jsPsych. Used a forked version of [Corsi Blocks](https://github.com/jspsych/jspsych-contrib/tree/main/packages/plugin-corsi-blocks) plugin by Josh de Leeuw.

自适应视觉 CORSI 任务，使用 jsPsych 编写。改编了 Josh de Leeuw 的 [Corsi Blocks](https://github.com/jspsych/jspsych-contrib/tree/main/packages/plugin-corsi-blocks) 插件。
